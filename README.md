# Personal Finance Manager

A Python CLI application for tracking personal income, expenses, categories, and balance.

## Features

- Add income
- Add expenses
- Categorize expenses
- View all transactions
- Calculate total income
- Calculate total expenses
- Calculate current balance
- View category-wise expense summary
- Save transactions using JSON
- Load saved transactions automatically
- Assign unique transaction IDs
- Store transaction dates
- Delete transactions
- Input validation

## Technologies Used

- Python
- JSON
- Git
- GitHub
